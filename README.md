# Project Thesis

DHIS2 to FHIR Pipeline for Immunization Data.

## Folder Structure
- `data/`: Raw, interim, cleaned, and external datasets.
- `notebooks/`: Jupyter notebooks for exploration.
- `scripts/`: Python scripts for ETL and mapping.
- `outputs/`: Generated reports, figures, and FHIR JSON.
- `docs/`: Documentation and academic deliverables.
- `tests/`: Automated tests.
